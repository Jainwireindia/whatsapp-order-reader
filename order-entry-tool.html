      Google Sheet connection

      Links this browser to the Master List Google Sheet (and Advanced Read for photos). Your passcode decides the location. The device name is written in the Sheet's Log next to every change made here. Kept in this browser only — never in the tool file or a backup.

      Check Master List

      Finds products that read as the same item (so the code can't choose between them and those lines come up orange), an alias given to two items, a party alias that is another party's name, and parties whose names differ only in spelling. Nothing is changed — it only lists them.
